# 가만히 감자 챌린지

움직이면 지는 병맛 챌린지. 단일 `index.html`.

- 마우스 이동 / 클릭 / 키보드 / 스크롤 / 우클릭 / 탭 전환 전부 실패
- 5스테이지 (10 / 20 / 30 / 45 / 60초), 방해는 점점 심해진다
- 방해: 장면 전환 함정 7종(가짜 감자 게임, 가짜 편의점 게임, 가짜 GAME CLEAR, 가짜 일시정지 메뉴, "아무 키나 누르세요", 별점 설문, 종료 카운트다운) — 화면이 통째로 바뀌어도 입력하면 "돌아와!" 소환 실패
- 방해: 거짓말하는 타이머, 가짜 팝업, 가짜 "응답 없음", 엄마 전화, 가짜 실패 화면, 화면 뒤집힘, 섬광
- 5스테이지 클리어 후 `🔥 지옥 스테이지(90초)` 해금
- 소리: 타이틀의 🔊 또는 `M` 키 (플레이 중 키보드는 실패)
- 모바일은 화면에서 손만 떼면 된다
