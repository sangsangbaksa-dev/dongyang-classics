# 출근하는 감자 DX 얼티밋 리마스터

클릭/스페이스로 감자를 날려 대파를 피하는 초저퀄 병맛 HTML5 게임. 단일 `index.html`.

- 6 스테이지(출근길 → 엘리베이터 → 회식 → 야근 → 월요병 → 대표이사실) + 최종 보스 + 엔딩 크레딧
- 무사고 기준 플레이타임 약 12분 (스테이지당 100초 x 6 + 보스 약 90초 + 크레딧 30초)
- 25초 단위 체크포인트, 진행 상황 자동 저장(이어하기). 타이틀에서 `N` 키로 새로 시작
- 아이템: ☕무적 💰월급 🍟동족상잔 / 장애물: 대파, 👔부장님
