# 출근하는 감자 DX : 극한 출근

클릭/스페이스로 감자를 날려 대파를 피하는 초저퀄 병맛 + 극악 rage 게임. 단일 `index.html`.

- 5 스테이지(출근길 / 와이파이 불안정 / 대파가 도망간다 / 중력 반전 / 수줍은 대파) + 가짜 엔딩 + 보스 2페이즈 + 엔딩
- 무사고 기준 약 5분 (스테이지당 30초)
- 병맛: 지나가는 카메오(닭/UFO/거북이...), 🍌 바나나(화면 뒤집힘), 가짜 월급, 이상한 알림 대사
- 엔딩은 갑자기 진지합니다. 아무것도 기대하지 마세요
- 화나게 하는 장치: 입력 지연, 도망가는 대파, 투명 대파, 가짜 월급, 가짜 GAME CLEAR, 되살아나는 보스,
  "97%에서 사망" 표시, "광고 보고 부활" 함정(스테이지 1로 돌아감)
- 진행 상황 자동 저장(이어하기). 타이틀에서 `N` 키로 새로 시작

## itch.io 업로드
1. `zip -j potato.zip index.html`
2. itch.io → Kind of project: **HTML** → zip 업로드 → "This file will be played in the browser"
3. Embed 크기 360x480 (또는 fullscreen)
