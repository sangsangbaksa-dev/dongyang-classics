# 百家爭鳴 · 전국난투

동양고전 탐구반 홍보용 2D 격투 게임. 한 사람이 **90초 안에** 체험을 끝내도록 설계했습니다.

| 단계 | 시간 |
| --- | --- |
| 타이틀 | 터치/키 입력 시 바로 진행 |
| 학파 선택 | 최대 12초 (시간이 다 되면 현재 선택으로 자동 시작) |
| 대결 (1판) | 최대 50초 + 연출 약 6초 |
| 결과 + 동아리 홍보 | 15초 뒤 자동으로 타이틀 복귀 |

## 실행

빌드가 필요 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 모바일은 화면에 터치 버튼이 나타납니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A D / ← → | 이동 |
| W / ↑ | 점프 |
| S / ↓ | 방어 |
| J (또는 `,`) | 약공격 |
| K (또는 `.`) | 강공격 |
| L (또는 `/`) | 필살기 (기 50) |
| U (또는 `;`) | 극의 (기 100) |
| M | 소리 끄기/켜기 |
| Esc | 처음으로 |

약공격이 적중하면 강공격이나 필살기로 이어 갈 수 있습니다.

## 학파

| 학파 | 인물 | 필살기 | 극의 |
| --- | --- | --- | --- |
| 유가 | 공자 | 극기복례 — 반격 자세 | 인자무적 — 거대한 충격파 |
| 도가 | 장자 | 호접지몽 — 추적 나비 | 소요유 — 나비 떼 |
| 법가 | 한비자 | 신상필벌 — 형벌의 기둥 | 법불아귀 — 5연속 엄벌 |
| 묵가 | 묵자 | 겸애 — 회복 + 방패 | 비공 — 성벽 파동 + 회복 |
| 병가 | 손자 | 병귀신속 — 무적 돌진 | 출기불의 — 순간이동 6연참 |
| 명가 | 공손룡 | 백마비마 — 백마 돌진 | 이견백 — 백마 3연속 |

## 홍보 문구 바꾸기

`src/game.js` 맨 위의 `PROMO` 를 수정하세요. `contact` 에 모집 안내(오픈채팅 링크, 인스타 계정 등)를 넣으면 결과 화면에 표시됩니다.
체험 시간은 같은 파일의 `FIGHT_SECONDS`, `SELECT_SECONDS`, `RESULT_SECONDS` 로 조절합니다.

## 구조

- `src/data.js` — 캐릭터, 스테이지, 키 설정
- `src/audio.js` — WebAudio 효과음과 오음계 배경음 (외부 파일 없음)
- `src/render.js` — 배경, 캐릭터, 투사체, 효과 그리기
- `src/game.js` — 전투 로직, AI, 화면 흐름
