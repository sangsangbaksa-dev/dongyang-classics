# 百家爭鳴 · 전국난투

동양고전 탐구반 홍보용 2D 격투 게임. 한 사람이 **90초 안에** 체험을 끝내도록 설계했습니다.

| 단계 | 시간 |
| --- | --- |
| 타이틀 | 터치/키 입력 시 바로 진행 |
| 학파 선택 | 최대 12초 (시간이 다 되면 현재 선택으로 자동 시작) |
| 대결 (1판) | 최대 65초 + 연출 약 5초 |
| 결과 + 동아리 홍보 | 12초 뒤 자동으로 타이틀 복귀 |

## 실행

빌드가 필요 없는 정적 페이지입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 모바일은 화면에 터치 버튼이 나타납니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A D / ← → | 이동 |
| W / ↑ | 점프 |
| S / ↓ | 방어 |
| J (또는 `,`) | 약공격 |
| K (또는 `.`) | 강공격 |
| L (또는 `/`) | 필살기 (기 50) |
| U (또는 `;`) | 극의 (기 100) |
| I (또는 `'`) | 돌진기 (기 소모 없음, 쿨타임 2.5초) |
| H (대결 중) / R (타이틀·선택) | 규칙 보기 (대결 중에는 일시정지) |
| M | 소리 끄기/켜기 |
| Esc | 처음으로 |

약공격이 적중하면 강공격이나 필살기로 이어 갈 수 있습니다.

**돌진기**는 모든 학파가 쓰는 기본기입니다. 기를 쓰지 않고 앞으로 달려 한 번 벱니다. 막히면 후딜이 길어 반격당하고, 점프로 피할 수 있습니다.
학파마다 이름이 다릅니다 (직간, 어풍, 엄진, 충차, 기습, 백구과극).

## 기(氣) 게이지

기가 50 이상이면 필살기(L), 100이면 극의(U)를 쓸 수 있습니다. 충전량은 `src/game.js` 의 `METER_GAIN` (현재 ×1.5) 으로 조절합니다.

| 상황 | 기 증가량 |
| --- | --- |
| 약공격 적중 | +10.5 |
| 강공격 적중 | +18 |
| 투사체 적중 | +6 ~ 12 |
| 맞았을 때 | 입은 피해 × 1.35 |
| 방어 성공 | 막은 쪽 +4.5 |

규칙 화면(`src/rules.js`)에도 같은 내용이 정리되어 있습니다.

## 밸런스

같은 AI끼리 전 조합(30쌍, 좌우 교대)을 수천 판 시뮬레이션해서 학파별 승률을 맞췄습니다.
AI 성향 3종(초보/중급/고급) 평균 승률이 모두 48~52% 안에 있습니다.
캐릭터 수치는 `src/data.js`, 필살기와 극의 수치는 `src/game.js` 의 `SPECIALS`, `ULTS` 에 있습니다.

## 난이도

학파 선택 화면 상단 칩이나 W/S(↑↓)로 고릅니다. 마지막 선택은 브라우저에 저장됩니다.

| 난이도 | CPU 체력 | CPU 공격력 | 특징 |
| --- | --- | --- | --- |
| 하 | ×0.6 | ×0.45 | 느리고 약함, 막지도 연계하지도 않음 |
| 중 | ×0.72 | ×0.58 | 가끔 필살기를 쓰지만 공격이 느슨함 |
| 상 | ×0.92 | ×0.88 | 기본기를 가끔 막고 약하게 응징 |
| 최상 | ×1.06 | ×1.06 | 빈틈 응징, 연계, 투사체 회피 |
| 불가능 | ×1.19 | ×1.16 | 대부분의 공격에 반응하고 확실히 응징 |

난이도 수치는 `src/data.js` 의 `DIFFS` 에서 조정합니다.

## 학파

| 학파 | 인물 | 필살기 | 극의 |
| --- | --- | --- | --- |
| 유가 | 공자 | 극기복례 — 반격 자세 | 인자무적 — 거대한 충격파 |
| 도가 | 장자 | 호접지몽 — 추적 나비 | 소요유 — 나비 떼 |
| 법가 | 한비자 | 신상필벌 — 형벌의 기둥 | 법불아귀 — 5연속 엄벌 |
| 묵가 | 묵자 | 겸애 — 회복 + 방패 | 비공 — 성벽 파동 + 회복 |
| 병가 | 손자 | 병귀신속 — 무적 돌진 | 출기불의 — 순간이동 6연참 |
| 명가 | 공손룡 | 백마비마 — 백마 돌진 | 이견백 — 백마 3연속 |

## 홍보 문구 바꾸기

`src/game.js` 맨 위의 `PROMO` 를 수정하세요. `contact` 에 모집 안내(오픈채팅 링크, 인스타 계정 등)를 넣으면 결과 화면에 표시됩니다.
체험 시간은 같은 파일의 `FIGHT_SECONDS`, `SELECT_SECONDS`, `RESULT_SECONDS` 로 조절합니다.

## 구조

- `src/data.js` — 캐릭터, 스테이지, 키 설정
- `src/audio.js` — WebAudio 효과음과 오음계 배경음 (외부 파일 없음)
- `src/render.js` — 배경, 캐릭터, 투사체, 효과 그리기
- `src/game.js` — 전투 로직, AI, 화면 흐름
