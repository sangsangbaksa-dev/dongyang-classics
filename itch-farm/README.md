# 감자 농장 (버그 있음)

버그가 의도된 방치형 감자 클리커. 단일 `index.html`.

- 감자를 눌러 키우고 업그레이드를 사서 누적 20,000개를 모으면 대파 대왕에게 인수합병된다 (약 4~5분)
- 의도된 버그: NaN/음수/오버플로우 표시, 상점 버튼 뒤바뀜(클릭 순간 바뀌기도 함), 클릭 2배/씹힘, 서버 롤백,
  할머니의 감자 도둑질, 국세청 팝업, 블루스크린, "광고 2배"(실제로는 0.5배), 도박 상자
- 🐛 버그 벌레를 잡으면 보상, 놔두면 수입이 반토막
- 소리: `M` 키 또는 타이틀의 🔊
- 모든 버그는 게임 안에서만 일어난다 (브라우저/저장 데이터 영향 없음)
